# Crate oak

Original MIT artwork generated by `scripts/crate-room-wood.go`. The 256×256
textures use growth rings, oval knots, open grain, checks and plank variation.
Panel/lid joints and darker frame grain remain seamless across the one-metre
repeat; the FPS Kit prefab supplies the actual crate frame geometry.

Run `mise run generate-crate-room-wood` from the CLI root to regenerate, or
`mise run check-crate-room-wood` to verify exact bytes. The local prefab material
overrides preserve the checksum-pinned FPS Kit archive. Materialize's wood preset
generates normal, height, AO and reflectance maps with stronger local relief.
These are albedo inputs, without painted directional light or contact shadows.
