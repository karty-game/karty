# Crate room sounds

Original synthesized mono PCM16 WAV effects, at 24 kHz, licensed under this
repository's MIT license. No external recordings or tools are required.

Run `mise run generate-crate-room-sounds` from the CLI root to regenerate the
short pneumatic shot, cartoon blast and resonant wooden knock.
`mise run check-crate-room-sounds` checks exact generated bytes.

Clips retain headroom and use short attack/release envelopes. Crate gain follows
impact strength, with a minimum speed loss, a 400 ms per-crate cooldown and at
most one impact every 133 ms across the room. Four impact voices and four blast
voices include retirement time in their budgets. Initial/reset settling is
muted for 750 ms. Sources use XYZ distance and listener-relative stereo panning.
